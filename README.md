AgriScan 🌱

AgriScan is a smart agriculture system designed to help farmers monitor soil conditions and make better farming decisions.

Features

- Farm management and soil scanning.
- Soil moisture and temperature monitoring.
- Crop-specific soil analysis.
- ESP32 device integration.
- Agricultural information and recommendations.

Project Structure

- "Frontend/" — Web application.
- "Backend/" — Server-side logic and API.
- "Database/" — Database files.
- "ESP32-Wokwi/" — Device code and simulation.

Developed by Team AgriScan.
